# Muse Studio

前端是一套纯浏览器漫画创作工作台，支持标准漫画、长漫画和独立四格。

## 运行

```sh
cd web
npm ci
npm run dev
```

`npm run build` 生成 `dist/`。Vite 的 `envDir` 显式设为 `false`，不加载环境文件；模型配置仍由用户在界面中填写。

## 交互流程

1. **创意设定**：写下故事灵感，选择角色、画风、漫画类型及对白语言。
2. **剧情分镜**：使用模型生成，或者展开提示词并复制到外部工具，粘贴返回结果后解析。长漫画和四格先确认梗概，再进入分镜。
3. **图片成稿**：检查分镜、准备图片提示词、调用图片模型并下载结果。底部入口可导出项目 JSON。

左侧的模型设置、项目历史、运行日志以弹窗打开，可用 Escape 关闭。生成失败会在工作区显示错误；缺少模型配置时直接打开设置。草稿自动保存到本机浏览器，历史最多保留 20 项，生成图片需单独下载。

`App.jsx` 提供稳定的界面骨架，`app.js` 管理生成引擎、持久化和工作流。工作区使用 `memo` 隔离 React 更新，避免切换主题时替换引擎管理的 DOM。`studio.css` 定义工作台布局，复用 `styles.css` 中已有的生成结果组件。

## 验证

安装 Google Chrome 后运行 `npm test`。Playwright 会启动本地 Vite 服务，验证三种漫画的手动流程、输入引导、导出、草稿恢复、设置入口、中英文、主题切换与移动布局。不发送真实模型请求，也不需要 API Key。

桌面和手机截图输出到 `test-results/`，该目录不提交。真实模型的网络连通性、生成质量和计费需使用用户自行配置的服务验证。
